# Operation Island Spoke

LLAB 7 classroom GLP (AFROTC Det 055, 6 Nov 2026). Training Objective WF 1.3: apply wargaming principles to analyze and solve a tactical problem.

A fighter wing at Andersen AFB, Guam balances flying jets today against having jets ready tomorrow, over four days that climb from deterrence to defending the base.

**Proctor Calculator:** https://jtfassbinder-lab.github.io/island-spoke/
